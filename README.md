 Telecom Churn Analysis

This project analyzes customer churn in a telecom dataset to identify key factors influencing why customers leave. The analysis is performed in Python using the Jupyter Notebook Telecom_churn_rate.ipynb.

 What’s Inside

Data cleaning & preprocessing

Exploratory data analysis (EDA)

Feature engineering

Churn behavior insights

 Tech Stack

Python

Pandas / NumPy

Matplotlib / Seaborn

Jupyter Notebook

 Key Findings (Summary)

Low usage and inconsistent recharge patterns correlate with higher churn

Missing recharge values reveal meaningful customer behavior

Engagement and usage metrics strongly influence churn
